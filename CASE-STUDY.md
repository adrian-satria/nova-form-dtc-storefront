# NOVA FORM — Portfolio Case Study

## Overview
NOVA FORM is a fictional DTC skincare storefront designed as a personal portfolio project.

## Challenge
Create a modern DTC storefront that communicates product value quickly, keeps the product catalog simple, and provides clear calls to action across desktop and mobile.

## Approach
1. Established a minimal visual identity for a fictional skincare brand.
2. Built a high-impact hero section with a direct shopping CTA.
3. Added a three-product collection with clear product names, descriptions and pricing.
4. Added trust/value points to reduce information friction.
5. Added a brand-story section to establish product positioning.
6. Added customer-review content for social proof.
7. Implemented a functional front-end cart interaction.
8. Added responsive behavior for smaller screens.

## Result
A complete, responsive storefront prototype that can be adapted to WordPress + WooCommerce + Elementor for a production e-commerce implementation.

## Note
This is explicitly a personal/demo project and does not represent paid client work.
