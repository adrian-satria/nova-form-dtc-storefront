# NOVA FORM — GitHub Pages Deployment

## Repository
Recommended repository name:
`nova-form-dtc-storefront`

Make the repository **Public** if you are using GitHub Free.

## Upload
Upload the contents of this folder to the root of the repository. The `index.html` file must remain at the repository root.

## Pages
1. Open **Settings → Pages**.
2. Under **Build and deployment → Source**, choose **GitHub Actions**.
3. Push the files to `main`.
4. Open the Actions tab and wait for the Pages workflow to finish.
5. GitHub will show the live URL in the workflow/environment and Pages settings.

GitHub Pages can publish static HTML, CSS and JavaScript directly from a repository. This project contains no server-side code or real payment processing.
